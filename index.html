WHAT I BUILT.

งานนี้เป็นการเขียนเว็ปไซด์ Learning Portfolio แบบหน้าเดียว
ไว้เก็บผลงานการแข่งกีฬาในช่วงที่ผ่านมา มีส่วนประกอบคือ รูปการแข่งกีฬา และ รายการที่แข่ง
โดยการเปิดเว็ปไซด์จากเครื่องของตัวเองจะมีเพียงแค่ Web Browser(Web Client) ทำหน้าที่อ่านไฟล์ และประมวลผล
โดยที่ไม่มี Web server เกิดขึ้น เพราะ Browser จะทำการดึงข้อมูลจากตัวฮาร์ดดิสในเครื่องของเราโดยตรง
โดยที่ไม่ต้องไปขอข้อมุลจาก Server

HOW I BUILT.

ผมเริ่มจากการลองวางแผนว่าจะใส่ข้อมูลอะไรไว้ในเว็ปบ้าง เช่น รูปควรจะอยู่ตรงไหน หัวข้อในส่วนนี้ต้องเขียนอะไรบ้าง ต้องการข้อมูลอะไรเพิ่มไหม
จากนั้นก็มาเขียนตัวโครง HTML แล้วก็พยายามเขียนให้ถูกต้องตามความต้องการของงาน หลังจากนั้นก็ทำการ LINK CSS
เข้ามาใน HTML แล้วไปทำการตกแต่งตัวเว็ปไซด์ใน CSS ต่อให้สวยงาม และดูน่าอ่าน
เครื่องมือที่ใช้คือ VS code แหล่งข้อมูลที่ศึกษาเพิ่มเติม "สไลด์อาจาย์ร" "W3school" และ "AI" มาช่วยในการอธิบายในส่วนที่ยังไม่เข้าใจ หรือติดขัด
